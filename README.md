# Beyond the Interface — UX Team Inspiration Day

Companion app (PWA prototype) for the UX Team Inspiration Day, Zürich, 23 November 2026: agenda, guided observation prompts for the two exhibitions, an on-device work log, and Markdown/JSON export. All data stays on the participant's device (localStorage).

**Open the app:** https://midnghtmauler.github.io/ux-inspiration-day/

## Install on your phone

- **Android (Chrome/Edge):** open the link, tap the install prompt or menu → *Add to Home screen*.
- **iPhone (Safari):** open the link, tap *Share* → *Add to Home Screen*.

Once installed it works offline — useful in museum basements and on the train.

Internal prototype; not indexed (noindex). Please don't share the link outside the team.
